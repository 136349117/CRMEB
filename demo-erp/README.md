# 码农老赵 · 工业互联网 ERP 演示大屏

给抖音录屏用的本地/云端演示页，深色指挥舱风格，含随机经营数据与产品图。

## 启动

```bash
cd demo-erp
python3 -m http.server 8088
```

浏览器打开：http://127.0.0.1:8088/?demo=1

- 账号无需登录
- `?demo=1` 会自动巡航：指挥舱 → 产品 → 订单 → 制造 → 物联 → 设备 → 仓储 → 档案 → 财务 → 人力
- 也可点右上角「自动巡航（录屏）」

## 内容

工业互联网 + **自动化设备**（PLC、变频器、伺服、HMI、远程 IO）小公司 **码农老赵**。演示金额均为几万～几十万，单笔不超过 50 万。含库存、设备台账、档案、财务与人力资源演示。
