# 星枢智造 · 工业互联网 ERP 演示大屏

给抖音录屏用的本地/云端演示页，深色指挥舱风格，含随机经营数据与产品图。

## 启动

```bash
cd demo-erp
python3 -m http.server 8088
```

浏览器打开：http://127.0.0.1:8088/?demo=1

- 账号无需登录
- `?demo=1` 会自动巡航：指挥舱 → 产品 → 订单 → 制造 → 物联 → 仓储
- 也可点右上角「自动巡航（录屏）」

## 内容

工业互联网企业 **星枢智造 STARAXIS**：边缘网关、工业相机、振动传感器、5G 模组、PLC、工业平板、AGV、AR 眼镜、能效网关。
